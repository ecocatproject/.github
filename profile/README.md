# EcoCAT = Ecosystem Conservation Assessment Tools

This project aims to develop an open, modular application to assess
ecosystem distribution, trends, function, degradation and risk of
collapse following the IUCN Red List of Ecosystems guidelines

## Tools

<a href="https://map.ecocatproject.org" target="_blank"><strong>Mapping
tool</strong></a>: automated ecosystem mapping and how they change over
time.

<a href="https://assess.ecocatproject.org"
target="_blank"><strong>Assessment tool</strong></a>: assess ecosystem
status following Red List of Ecosystems Guidelines.
